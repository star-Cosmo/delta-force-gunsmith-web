# 三角洲行动 · 改枪工坊

## 项目简介

三角洲行动改枪工坊是一个本地运行的 Web 应用，帮助玩家根据目标属性自动选配枪械配件，并生成改枪码。

## 功能特点

- 展示枪械六项核心属性（后坐力控制、据枪稳定性、操控速度、有效射程、腰射精度、护甲伤害）
- 可拖动的属性滑块，设定目标属性值
- 根据目标属性自动推荐最优配件组合
- 生成游戏内可用的改枪码
- 支持精校属性调整

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 技术栈

- HTML5 + CSS3 + 原生 JavaScript
- 无需后端，纯前端运行
